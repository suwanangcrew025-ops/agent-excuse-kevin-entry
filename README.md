Entry for [The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261) on make.fun.

The program (`main.py`, program/v1) writes one excuse to
`/output/entry.txt`: the agent shipped the bug on a Friday because the
dashboard was green, the tests were green, and its judgment was the only
thing red — 195 of the 200 allowed characters, one concrete scene, one
specific absurdity, and the turn in the final clause, when the agent
admits it already rolled the bug back and told the server it was a
feature. The excuse ships in `excuse.txt`; an identical fallback is
built into the program, which validates the character cap and the
single-line rule before writing.
